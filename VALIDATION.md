# Проверка версии

- `npm run build`: успешно, production-сборка Next.js.
- `npm test`: 8/8 серверных проверок успешно.
- Проверка API на production-сервере: успешно. Изоляция гостей, защита same-origin, конфликт версий, корзина, оплата, чтение сохранённого заказа.
- Фотографии: 8 файлов визуально проверены при подборе.
- Визуальная проверка сайта в облачном браузере: не завершена. Среда предпросмотра отвечала 502; нельзя утверждать, что desktop/mobile интерфейс проверен в браузере.
- Vercel: не опубликовано. Требуется подключённый аккаунт Vercel и PostgreSQL/DATABASE_URL. Секреты не включены.

Критические правила покрыты тестами: серверная цена, разделение заказов по продавцам, идемпотентность тестовой оплаты, отказ без изменения остатков, запрет превышения остатка, границы возврата, восстановление остатка при отмене, отзыв после получения, модерация нового предложения, защита чужих демообъявлений от редактирования, защита занятого времени записи, независимость этапа CRM от оплаты.
